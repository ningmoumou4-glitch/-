# 国内下沉短剧剧本创作工作流

> 专门对接国内的下沉短剧项目

## 工作流功能

### 一、扒剧（参考优化）
1. 检测输入文件 - 扫描提交的 Markdown/Word/PDF
2. 解析内容 - 提取题材/人物关系/套路热梗
3. 生成结构化数据 - 转换为 JSON 格式供 AI 调用
4. 创意组合 - 结合题材库+人物关系库 生成新剧提案

## 快速开始

### 1. 上传剧本素材
将文件放到 input/ 目录，然后提交

### 2. 工作流自动执行
工作流会自动生成所有结构化数据

### 3. 查看输出
在 output/json/ 目录中查看生成的文件
